Lumen Keep is an original arena-defense game: guard the last lantern in a dark grove against eight waves of shades. Move with WASD or the arrow keys, aim with the mouse, hold click or Space to shoot bolts of light, and pick one boon between waves — Twin Light, Bright Bolts, Rapid Glow, Swift Boots, Lantern Mend or Swift Heart. Shades gnaw at the lantern if they reach it, spitters throw dark orbs from a distance, and the final wave brings the Gloomlord. Survive all eight waves to win. Synthesized WebAudio sound, particles, screen shake and a best score kept in localStorage. No libraries, no network, no build step — plain static files under game/.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
